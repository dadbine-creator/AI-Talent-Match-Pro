Authentication

All API requests require an API key passed in the X-API-Key header. Create keys in your Admin panel under Developer Settings.

http
GET /api/v1/candidates HTTP/1.1
Host: api.aitmp.io
X-API-Key: aitmp_your_key_here
Content-Type: application/json
Response — Invalid Key
{
  "detail": "Invalid or revoked API key"
}
Quick Start

Get up and running in 60 seconds. Choose your language:

python
import requests

API_KEY = "aitmp_your_key_here"
BASE_URL = "https://api.aitmp.io/api/v1"

headers = {"X-API-Key": API_KEY}

# Get all candidates
response = requests.get(f"{BASE_URL}/candidates", headers=headers)
candidates = response.json()

# Generate a narrative
narrative = requests.post(
    f"{BASE_URL}/narratives/generate",
    headers=headers,
    json={
        "candidate_id": "candidate_uuid_here",
        "narrative_type": "full"
    }
).json()

print(narrative["narrative"])
javascript
const API_KEY = "aitmp_your_key_here";
const BASE_URL = "https://api.aitmp.io/api/v1";

const headers = { "X-API-Key": API_KEY };

// Get all candidates
const candidates = await fetch(`${BASE_URL}/candidates`, { headers })
    .then(r => r.json());

// Generate a narrative
const narrative = await fetch(`${BASE_URL}/narratives/generate`, {
    method: "POST",
    headers: { ...headers, "Content-Type": "application/json" },
    body: JSON.stringify({
        candidate_id: "candidate_uuid_here",
        narrative_type: "full"
    })
}).then(r => r.json());

console.log(narrative.narrative);
bash

Webhooks

Receive real-time events when candidates are created, narratives generated, or billing events occur. All deliveries are signed with HMAC-SHA256.

Verifying webhook signatures (Python)
import hmac, hashlib

def verify_webhook(payload: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(
        secret.encode(),
        payload,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)

# In your endpoint:
signature = request.headers.get("X-AITMP-Signature")
is_valid  = verify_webhook(request.body, signature, WEBHOOK_SECRET)
API Scopes

Each API key must be granted specific scopes. Use the minimum scopes required.

candidates:read
Read candidate data
candidates:write
Create, update, delete candidates
narratives:generate
Generate AI narratives
analytics:read
Read usage + talent analytics
webhooks:manage
Create + manage webhooks
forecasts:read
Read hiring forecasts
cost:read
Read cost analytics
sla:read
Read SLA metrics + alerts
